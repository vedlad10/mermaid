Two-step sign-in

This practice requires two-step sign-in. Add Mermaid to an authenticator app (Google Authenticator, Microsoft Authenticator, 1Password) using this key, then enter the code it shows.

Open in an authenticator app on this device

Enter the 6-digit code from your authenticator app. A recovery code also works.

Save your recovery codes

Each code signs you in once if you lose your phone. Store them somewhere safe — they will not be shown again.
